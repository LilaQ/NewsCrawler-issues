NewsBar is a native macOS menu-bar news reader. Public support is handled through this GitHub repository.

Open a support issue

Before reporting

  • Use the newest available NewsBar build.
  • Check the in-app Source Status page for feed-specific failures.
  • For purchases, open Settings and choose Restore Purchases.

Include

  • macOS version and NewsBar version/build;
  • affected language, category or source;
  • steps to reproduce and expected/actual behavior;
  • a screenshot only if it contains no personal information.
Do not publish secrets. Never include credentials, receipts, private feed URLs, personal information or sensitive paths/logs in a public issue. Security reports should use GitHub’s private vulnerability reporting.

Data deletion

NewsBar has no account or cloud profile. Remove custom sources, bookmarks and topic rules in the app; reset local recommendations in Settings. Deleting NewsBar’s application container removes its remaining local data.

Rights concerns

Publishers and rightsholders can use the dedicated rights-report issue form. Do not include confidential material.
