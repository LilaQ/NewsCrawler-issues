NewsBar uses native macOS controls, labels icon-only actions for assistive technologies, supports keyboard focus and follows the system light/dark appearance.

Release validation

Before claiming any App Store Accessibility Nutrition Label, all common tasks—including onboarding, browsing, reading, settings, purchasing and restoring—must be tested against Apple’s current criteria on the signed release build. Until that audit is complete, the App Store declaration remains a release blocker rather than an unsupported claim.
