Soporte de NewsBar

IdiomasPrivacidadCondicionesAccesibilidad

NewsBar es un lector de noticias nativo para la barra de menús de macOS. El soporte público se gestiona en este repositorio de GitHub.

Crear una solicitud

Antes de informar

  • Usa la versión más reciente.
  • Consulta el Estado de fuentes de la app para problemas de feeds.
  • Para compras existentes, selecciona Restaurar compras en Ajustes.

Incluye

  • versiones de macOS y NewsBar;
  • idioma, categoría o fuente afectados;
  • pasos, resultado esperado y resultado real;
  • capturas sin información personal.
No publiques secretos. No incluyas credenciales, recibos, feeds privados, datos personales ni registros sensibles en una incidencia pública. Usa los informes privados de vulnerabilidades de GitHub para seguridad.

Eliminar datos

NewsBar no tiene cuenta ni perfil en la nube. Elimina fuentes, marcadores y reglas en la app, restablece las recomendaciones en Ajustes o borra el contenedor de la app para eliminar los datos locales restantes.
