NewsBar est un lecteur d’actualités natif dans la barre des menus de macOS. L’assistance publique passe par ce dépôt GitHub.

Créer une demande

Avant de signaler

  • Utilisez la version la plus récente.
  • Consultez l’état des sources dans l’app pour les problèmes de flux.
  • Pour un achat existant, choisissez Restaurer les achats dans les réglages.

Informations utiles

  • versions de macOS et de NewsBar ;
  • langue, rubrique ou source concernée ;
  • étapes, résultat attendu et résultat observé ;
  • capture d’écran sans information personnelle.
Ne publiez aucun secret. Aucun identifiant, reçu, flux privé, donnée personnelle ou journal sensible dans un ticket public. Utilisez le signalement privé de vulnérabilité de GitHub pour la sécurité.

Suppression des données

NewsBar n’a ni compte ni profil cloud. Supprimez les sources, signets et règles dans l’app, réinitialisez les recommandations dans les réglages ou supprimez le conteneur de l’app pour effacer les données locales restantes.
